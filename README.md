## 🚀 Proyectos Destacados

### Sistema de Gestión de Notas Académicas
Portal educativo para gestionar calificaciones, usuarios, asignaturas y reportes.
- **Repositorio:** https://github.com/Craos6518/Proyecto-academico-version-andres
- **Aplicación en producción:** https://proyecto-academico-version-andres-git-main-craos-projects.vercel.app
- **Tecnologías:** Next.js, React, TypeScript, Tailwind CSS, Supabase (PostgreSQL, Auth, API REST)
- **Funciones clave:** control de acceso por roles, validaciones de rango de notas, cálculo automático de nota final, historial y auditoría
- **Entorno:** desarrollo asistido en v0.app con despliegue en Vercel

### To-Do List Project
Aplicación web responsive para crear, editar y organizar tareas con categorías y estados.
- **Tecnologías:** HTML, CSS, JavaScript
- **Funciones clave:** gestión de tareas, categorías (máx. 10), prioridades, estados (comenzada, culminada, aplazada)
- **Estructura:** páginas separadas para categorías, prioridades y estado; barra de navegación

### Calculadora Gráfica en C
Calculadora capaz de graficar polinomios y gestionar cuentas desde consola con archivos de texto.
- **Tecnologías:** C (librerías `conio.h` y `graphics.h`)
- **Funciones clave:** graficado de polinomios de cualquier grado y escalado de gráficos
- **Notas técnicas:** compatible con compiladores de 32 bits; no soporta divisiones, logaritmos ni raíces

### Sistema de Gestión de Inventario
Aplicación web para registrar productos, controlar stock y generar reportes.
- **Stack:** Frontend (HTML, CSS, JavaScript) y Backend (Node.js + Express + MySQL)
- **Funciones clave:** registro de productos, monitoreo de stock, reportes y autenticación con JWT
- **Estructura:** /frontend, /backend, /database y /tests
